Phase 6 – Project Testing

Testing was performed to verify that the PocketSmart AI application works correctly and that the main features provide the expected results.

2. Testing Objectives

The main objectives of testing were:

- To verify user registration and login.
- To verify planner forms.
- To verify recommendation generation.
- To verify budget allocation.
- To verify recommendation history.
- To verify page navigation.
- To identify and fix errors during development.

The Home Planner was tested using a sample budget and requirements.

5. Party Planner Testing

6. Jewelry Planner Testing

The Jewelry Planner was tested using budget, occasion, outfit style, metal preference, and notes.
