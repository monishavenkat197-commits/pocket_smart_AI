Phase 7 – Project Documentation

1. Project Title

PocketSmart AI – Smart Budget & Recommendation Assistant

2. Project Description

PocketSmart AI is a web-based application that helps users plan their budget and receive suitable recommendations based on their requirements.

The application provides three main planning areas:

- Home Interior Planner
- Party Planner
- Jewelry Planner

3. Purpose of the Project

The purpose of PocketSmart AI is to make budget planning simple and help users receive suitable recommendations according to their available budget and requirements.

4. Main Features

User Authentication

Users can register, login, and logout securely.

Dashboard

The Dashboard provides access to the available planners and recent recommendations.

Home Interior Planner

Users can enter their budget, room type, style, and required items to receive recommendations.

Party Planner

Users can enter their budget, event type, number of guests, city, and preferences to receive party planning recommendations.

Jewelry Planner

Users can enter their budget, occasion, outfit style, metal preference, and additional notes to receive jewelry recommendations.

Budget Allocation

The application provides an estimated allocation of the available budget across relevant categories.

Recommendation History

Previously generated recommendations are stored and can be viewed from the History section.

6. How to Run the Project

Step 1

Open the project folder in Visual Studio Code.

Step 2

Activate the Python virtual environment.

Step 3

Install the required dependencies using:

pip install -r requirements.txt

Step 4

Configure the required environment variables locally using the ".env" file.

Step 5

Start the FastAPI application using:

uvicorn app.main:app --reload

Step 6

Open the application in a web browser using:

http://127.0.0.1:8000

7. Working Process

The basic working process is:

Login → Dashboard → Select Planner → Enter Requirements → Generate Recommendations → View Results → Save History

8. Project Output

The application generates recommendations based on the user's requirements and budget.

The output includes:

- Recommendations
- Estimated prices
- Budget allocation
- Reasons
- Useful tips
- Disclaimer about estimated prices and availability
